# Grill-Resume

本地优先的 AI 简历生成工具。通过「引导式问答 → 逐条联网评估 → 综合润色导出」三步，把零散经历变成一份可导出的中文 Word 简历。AI 模型与联网搜索均由你自行配置 URL 和 Key，所有数据存在本机。

## 功能

- **引导式问答建档**：极简对话界面，AI 像顾问一样逐步追问，帮你梳理姓名、工作经历、项目、技能、教育与可量化成果。你只需用纯文字回答（无需上传文件），后台自动把内容结构化为人物档案。
- **档案工作台**：问答结束后生成人物档案页，以编辑器形式展示各字段，可自由查看和修改。
- **逐条联网评估**：基于目标岗位，对每条经历要点联网搜索佐证，逐条给出「相关性 / 可信度 / 稀缺度」评级与改进建议，并生成一段总体评价。
- **综合润色导出**：综合人物档案与评估报告，AI 吸收评估建议改写要点，生成结构化简历草稿，一键导出中文 Word（`.docx`）文档。

## 技术栈

Next.js 16（App Router / RSC / Server Actions）· React 19 · TypeScript · SQLite（better-sqlite3）· Tailwind v4 · docx。AI 走 OpenAI 兼容协议；联网搜索支持 Tavily / EXA。

## 本地启动

```bash
cd app
pnpm install
pnpm dev          # 开发服务，默认 http://localhost:3000
```

生产构建与启动（生产环境需设置 `RESUME_CONFIG_SECRET` 用于本地配置加密）：

```bash
pnpm build
RESUME_CONFIG_SECRET=<你的随机密钥> pnpm start
```

## 配置 AI 与搜索（首次必做）

模型和搜索都由你自己配置，应用不预设任何地址或密钥。打开 `/settings`：

1. **AI 连接**：填写名称、默认模型、Base URL（OpenAI 兼容，例如 `https://api.deepseek.com/v1`）、API Key，保存后可点「测试」验证连通。
2. **任务路由**（可选）：为问答 / 评估 / 润色分别指定连接与模型；不填则统一用默认连接。
3. **搜索渠道**（可选，供评估联网）：添加 Tavily 或 EXA 渠道及其 Key，可同时启用多个，评估时并发搜索并去重。

所有连接和密钥加密存储在本机。

## 使用流程

1. **新建档案**：首页点「新建档案」，进入问答页 `/intake/[id]`。
2. **问答建档**：在对话框里回答 AI 的引导提问，提供经历与成果。信息会被自动结构化入库。
3. **查看 / 修改档案**：问答完成后进入档案页 `/profile/[id]`，在工作台编辑器里核对、调整各字段。
4. **联网评估**：点「进入评估」，确认后对每条经历联网搜索并逐条评估，生成评估报告。
5. **润色导出**：点「进入润色」，AI 综合档案与评估报告生成简历草稿，点「导出 Word」下载 `.docx`。

顶部导航栏可在四步之间自由跳转。

## 数据与隐私

- 人物档案、问答日志、评估报告、简历草稿均存本机（SQLite + 本地文件），不上传。
- AI 连接与搜索的 Key 加密存储；错误信息经消毒后展示，不泄露上游响应内容。
- 联网评估会把相关经历内容发送给你配置的搜索渠道，评估页有显式确认按钮，不会自动外发。
