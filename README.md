# Grill-Resume

Grill-Resume 是一个本地优先的中文简历工作台。它把原始经历、岗位 JD、追问记录、已确认 STAR 证据和最终简历排版串成一个流程，帮助你从“素材很多但不知道怎么写”推进到“有证据、可编辑、可导出的中文简历”。

## 主要功能

- **项目式管理**：为不同求职方向创建项目，管理主简历和岗位版简历。
- **素材录入**：粘贴原始经历、岗位 JD、项目说明、职责成果等材料，作为后续追问和生成的基础。
- **Grill 追问**：围绕经历中的背景、任务、行动、结果、指标和证据继续追问，补齐弱项。
- **证据优先**：只有用户确认过的事实才会进入最终简历；缺证据的内容会停留在待确认状态。
- **隐私预览**：AI、联网搜索和导出等外发动作都会先展示将要发送的内容，确认后才执行。
- **岗位评估**：基于目标岗位检查简历完整度、影响力、可信度和 ATS 友好度。
- **AI 候选润色**：可生成不同语气的 bullet 候选，并通过 diff 对比后手动选择是否应用。
- **排版编辑器**：调整模块顺序、显隐、主题和字号；支持有边界的措辞微调，但不能新增事实。
- **中文 Word 导出**：导出 confirmed-only 的中文 `.docx` 简历，未确认内容不会被自动写入。

## 适合的使用场景

- 你有较多零散经历，需要被追问后整理成简历。
- 你希望简历内容可追溯，不想让 AI 编造事实。
- 你在针对某个岗位改简历，需要检查 JD 匹配度和 bullet 说服力。
- 你希望最终导出一份干净的中文 Word 简历，而不是只停留在聊天记录里。

## 本地启动

进入应用目录并安装依赖：

```bash
cd app
pnpm install
```

启动开发服务：

```bash
pnpm dev
```

默认访问：

```text
http://localhost:3000
```

生产构建与启动：

```bash
pnpm build
pnpm start
```

## 基本使用流程

1. **创建项目**
   打开首页，新建一个简历项目。项目会保存在本机 workspace 中。

2. **录入原始材料**
   在项目中粘贴原始经历、岗位 JD、项目说明、成果数据等内容。材料越具体，后续追问和候选 bullet 越有用。

3. **进入 Grill 追问**
   按页面提示回答追问。系统会优先补齐背景、任务、行动、结果、指标、证据等薄弱项。

4. **确认可用证据**
   对已经讲清楚的经历，手动确认并整理为 STAR 证据。未确认内容不会自动进入最终简历。

5. **生成和应用候选 bullet**
   可让 AI 基于已确认材料生成候选表达。应用前先看原文与候选的差异，再决定是否写入。

6. **评分与优化**
   使用评分页面检查完整度、影响力、可信度和 ATS 表达，按问题逐项优化。

7. **调整排版**
   在编辑器中调整模块顺序、显隐、主题、字号和行距。措辞微调会保留差异，并阻止新增无证据数字或实体。

8. **导出中文 Word**
   在导出页选择中文 Word。导出前会经过隐私确认，最终文件只包含已确认内容。

## AI 与联网搜索配置

Grill-Resume 可以在没有 AI 配置的情况下做本地录入、编辑、评分和导出。若要使用 AI 候选生成或联网评估，需要在应用内配置：

- **模型设置**：`/settings/models`
- **搜索设置**：`/settings/search`

配置后，相关请求仍会先进入隐私预览；取消确认不会发起外部请求。

## 数据与隐私

- 默认数据保存在本机。
- 手机、邮箱、本地路径、API key 等敏感字段不会作为普通外发内容展示或发送。
- AI 只提供候选，不直接确认事实。
- 联网搜索结果必须带来源；不可用时降级显示，不会伪造引用。
- 导出只使用 confirmed-only 内容，缺口会提示而不是自动补写。

## 常见问题

### 没有配置 AI 能不能用？

可以。你仍然可以创建项目、录入材料、回答追问、手动确认事实、编辑排版和导出简历。AI 相关按钮会要求先配置模型。

### 为什么编辑器不能随便新增事实？

Grill-Resume 的核心原则是 evidence-first。新增事实需要回到 Grill 追问中补证据，避免简历中出现无法追溯的数字、组织名或成果描述。

### 导出的 Word 为什么缺少某些内容？

导出只包含已确认内容。草稿、候选、待确认和已归档内容不会进入最终 Word。你可以回到 Grill 或编辑页面补齐确认。

### 联网搜索失败会怎样？

搜索失败会降级为不可用状态，不会生成虚假的公司信息、岗位结论或引用来源。

## 当前定位

Grill-Resume 关注中文简历的“证据收集、追问打磨、可信候选、排版导出”闭环。它不是自由写作编辑器，也不是让 AI 一键代写完整简历的工具。
