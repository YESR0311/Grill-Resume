# Grill-Resume

本地优先的中文简历工作台。把「原始经历 → 追问打磨 → 确认证据 → 岗位评估 → 候选润色 → 排版导出」串成一条 evidence-first 流程：只有你确认过的事实才会进入最终简历，AI 只产候选、不替你确认。

## 功能

- **项目式管理**：按求职方向建项目，分别维护主简历与岗位版简历，数据保存在本机。
- **素材录入**：粘贴原始经历、岗位 JD、项目说明、职责成果，作为追问与生成的基础。
- **Grill 追问**：围绕背景 / 任务 / 行动 / 结果 / 指标 / 证据补齐薄弱项，整理成 STAR 证据。
- **岗位评估**：基于目标岗位检查完整度、影响力、可信度与 ATS 友好度，给出可逐项优化的报告。
- **AI 候选润色**：生成不同语气的 bullet 候选，支持批量生成与批量应用；应用前先看 diff，再决定是否写入。
- **排版编辑器**：调整模块顺序、显隐、字号、行距；提供 `clean / classic / compact` 主题预设，切换预设会同时套用字体、字号、行距与页边距。措辞微调有边界，禁止新增无证据的数字或实体。
- **中文 Word 导出**：导出 confirmed-only 的 `.docx`，未确认内容不写入；单页适配会解释压缩决策，导出前经隐私预览确认。

## 本地启动

```bash
cd app
pnpm install
pnpm dev          # 开发服务，默认 http://localhost:3000
```

生产构建与启动：

```bash
pnpm build
pnpm start
```

## 使用流程

1. **建项目**：首页新建简历项目。
2. **录素材**：在 intake 页粘贴原始经历、JD、成果数据，越具体越好。
3. **Grill 追问**：按提示回答，优先补齐背景 / 任务 / 行动 / 结果 / 指标 / 证据。
4. **确认证据**：把讲清楚的经历手动确认为 STAR 证据，未确认内容不进简历。
5. **评分优化**：score 页检查完整度、影响力、可信度、ATS 表达，逐项改。
6. **润色候选**：coach/polish 页让 AI 生成候选 bullet，看 diff 后单条或批量应用。
7. **调排版**：编辑器里调模块顺序 / 显隐 / 主题预设 / 字号行距，措辞微调保留差异。
8. **导出 Word**：export 页导出中文 `.docx`，经隐私确认后只写入已确认内容。

## AI 与联网搜索配置

无 AI 配置时仍可本地录入、编辑、评分、导出；要用 AI 候选生成或联网评估需在应用内配置：

- 模型设置：`/settings/models`
- 搜索设置：`/settings/search`

配置后请求仍先进隐私预览，取消确认不会发起外部请求。

## 数据与隐私

- 数据默认存本机；手机、邮箱、本地路径、API key 等敏感字段不作为普通外发内容展示或发送。
- AI 只提供候选，不直接确认事实；新增事实须回 Grill 补证据。
- 联网搜索结果必须带来源，不可用时降级显示，不伪造引用。
- 导出仅用 confirmed-only 内容，缺口提示而非自动补写。

## 定位

聚焦中文简历的「证据收集 → 追问打磨 → 可信候选 → 排版导出」闭环。它不是自由写作编辑器，也不是 AI 一键代写简历的工具。
