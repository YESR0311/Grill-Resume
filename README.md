# Grill-Resume

本地优先的 AI 简历生成工具。通过「6 阶段引导式问答 → 逐条联网评估 → 综合润色导出」三步，把零散经历变成一份可导出的中文 Word 简历。AI 模型与联网搜索均由你自行配置 URL 和 Key，所有数据存本机。

## 功能

- **6 阶段引导式问答建档**：AI 像顾问一样，按「基本信息 → 工作经历 → 项目经历 → 技能 → 教育背景 → 补充证据」6 个阶段自由追问。每一阶段可随时结束进入下一阶段；后台静默把对话结构化为人物档案，无需上传文件、无需填表。
- **档案工作台**：问答结束后生成人物档案页 `/profile/[id]`，以编辑表单展示各字段，可自由查看和修改。
- **逐条联网评估**：基于目标岗位，对每条经历要点联网搜索佐证，逐条给出「相关性 / 可信度 / 稀缺度」评级与改进建议，并生成一段总体评价。
- **综合润色导出**：综合人物档案与评估报告，AI 吸收评估建议改写要点，生成结构化简历草稿，一键导出中文 Word（`.docx`）。导出文档强制 A4 竖版（210×297mm），所有模板预留小二寸（35mm×45mm）证件照占位符。
- **9 种模板一键切换**：5 主题（白蓝经典 / 学术论文 / 智能科技紫罗兰 / 时尚创意 / 黑蓝 ATS）× 4 文档族（时序 / 混合 / 功能 / ATS）的笛卡尔组合，每种组合决定照片位置 / 形状 / 主题色 / 字体。详情见 [9 模板与设计系统](#9-个简历模板)。

## 设计风格

- **配色**：design_sense 暖色调（奶白 `#F7F4EF` 背景 + 赭石 `#C4612F` 强调色 + 暖灰 `#E7E1D7` 分隔线）
- **字体**：Playfair Display（衬线，标题）+ Inter（无衬线，正文 / UI）
- **圆角**：卡片 12px，按钮胶囊形（999px）
- **布局**：四步流程页（问答 / 档案 / 评估 / 润色）统一用侧边栏（StepNavSidebar）+ 顶部 StepNav 的工作台结构；问答页侧边栏含 IntakeProgress 亮灯效果（实心 + 光晕 = 已覆盖，半透明 = 已写部分，空心 = 未覆盖）。

## 技术栈

Next.js 16（App Router / RSC / Server Actions）· React 19 · TypeScript · SQLite（better-sqlite3，带 schema 自愈）· Tailwind v4 · docx · Tiptap（富文本编辑）。AI 走 OpenAI 兼容协议；联网搜索支持 Tavily / EXA。

## 本地启动

```bash
cd app
pnpm install
pnpm dev          # 开发服务，默认 http://localhost:3000
```

生产构建与启动（生产环境需设置 `RESUME_CONFIG_SECRET` 用于本地配置加密）：

```bash
pnpm build
RESUME_CONFIG_SECRET=<你的随机密钥> pnpm start
```

## 配置 AI 与搜索（首次必做）

模型和搜索都由你自己配置，应用不预设任何地址或密钥。打开 `/settings`：

1. **AI 连接**：填写名称、默认模型、Base URL（OpenAI 兼容，例如 `https://api.deepseek.com/v1`）、API Key，保存后可点「测试」验证连通。
2. **任务路由**（可选）：为问答 / 评估 / 润色分别指定连接与模型；不填则统一用默认连接。
3. **搜索渠道**（可选，供评估联网）：添加 Tavily 或 EXA 渠道及其 Key，可同时启用多个，评估时并发搜索并去重。

所有连接和密钥加密存储在本机。

## 使用流程

顶部导航栏在四步之间自由跳转（未完成前序步骤的目标锁定）。

1. **新建档案**：首页 `/` 点「新建档案」或最近档案卡片，进入问答页 `/intake/[id]`。
2. **6 阶段问答建档**：在对话框里逐阶段与 AI 对话。每一阶段可等 AI 自动判定阶段完成（会收到「我先到这里」式收尾），或直接点右上「我先到这里」按钮手动进入下一阶段。
   - 阶段 1：基本信息（姓名 / 目标岗位 / 联系方式）
   - 阶段 2：工作经历（按 id 匹配公司 + 时间段 + 职责 + 成果）
   - 阶段 3：项目经历（项目名 + 角色 + 技术栈 + 亮点）
   - 阶段 4：技能（语言 / 框架 / 工具 / 软技能）
   - 阶段 5：教育背景（学校 / 专业 / 时间 / 课程 / GPA）
   - 阶段 6：补充证据（奖项 / 证书 / 论文 / 博客等）
   - 后台静默把每阶段对话解析为结构化字段写回档案；解析失败不会中断流程，partial 部分会显示「（部分）」标记。
3. **查看 / 修改档案**：进入档案页 `/profile/[id]`，在工作台编辑器里核对、调整各字段。点右上「去评估」进入下一步。
4. **联网评估**：评估页 `/evaluate/[id]`，点「开始评估」打开确认弹窗，确认后对每条经历联网搜索并逐条评估，生成评估报告。报告内嵌可滚动 ScrollArea 展示。
5. **润色导出**：润色页 `/polish/[id]`，左侧结构化编辑器（Tiptap 7 扩展，工具栏含字号 / 字重 / 行距 / 字间距 / 对齐）+ 右侧实时预览。
   - 顶部「模板」下拉切换 9 模板之一，证件照位置随之变化。
   - 顶部「风格」控件调字号 / 字重 / 行距 / 字间距 / 对齐 / 主题色 / 字体。
   - 点「导出 Word」下载 `.docx`（A4 竖版，与预览一致）。

## 文档族与主题（高级）

- **文档族**：`chronological`（时序）/ `hybrid`（混合）/ `functional`（功能）/ `ats`（ATS）
- **主题**：`白蓝经典` · `学术论文` · `智能科技紫罗兰` · `时尚创意` · `黑蓝 ATS`
- 组合规则由 `src/features/polish/template-style.ts` 中的 `getTemplateDesign(templateId)` 提供，每种组合定义 photo 位置、主题色、字体族、TopHeader 变体。
- 主题与证件照由 `TopHeader` 统一管理，避免各模板重复实现顶部区。

## 数据与隐私

- 人物档案、问答日志（每条带 dimension 标签）、评估报告、简历草稿均存本机（SQLite + 本地文件），不上传。
- AI 连接与搜索的 Key 加密存储；错误信息经 `toUserMessage` 消毒后展示，不泄露上游响应内容。
- 联网评估会把相关经历内容发送给你配置的搜索渠道，评估页有显式确认按钮，不会自动外发。
- SQLite schema 自愈：`intake_messages.dimension` 列、复合索引等在启动时由 `ensureSchema` 自动补全，无需手动迁移。
